# Friday Night — ألعاب جماعية

موقع ألعاب للجمعة يشتغل على GitHub Pages، ويستخدم Firebase للغرف أونلاين.

**الرابط:** https://fridaynight-sa.github.io

## الألعاب
| المجلد | اللعبة |
|---|---|
| `/` | الصفحة الرئيسية: الألعاب + خانة «ادخل برمز الغرفة» |
| `seenjeem/` | 🎬 سين جيم (مسلسلات وأفلام) |
| `outside/` | 🤫 برا السالفة |
| `sedq/` | 🤥 صدق ولا كذب |
| `mf/` | 👀 مين فينا؟ |
| `draw/` | 🎨 ارسم وخمّن |
| `dafour/` | 🤓 الدافور (أسئلة معلومات عامة بأربع خيارات) |
| `tv/` | 📺 شاشة العرض للتلفزيون (تشتغل مع كل الألعاب، وتمشي مع السهرة) |

كل الغرف رموزها 4 حروف. رموز سين جيم القديمة (`AB123`) والروابط القديمة (`الموقع/#AB123`) تشتغل بعد.

## السهرة (بدّل اللعبة)
- في أي غرفة، صاحبها يشوف «🔄 بدّل اللعبة» فوق. يختار لعبة، والكل ينتقل لها تلقائي **بنفس الرمز**.
- الترتيب بالميداليات: كل لعبة تخلص، الأول 🥇 والثاني 🥈 والثالث 🥉. الترتيب بعدد 🥇، وإذا تعادلوا فبعدد 🥈 ثم 🥉، فاللي فاز بلعبتين فوق اللي فاز بوحدة دايم. في سين جيم كل الفريق ياخذ ميدالية فريقه (صاحب الغرفة يتأكد مين في أي فريق).
- ما تنحسب إلا اللعبة اللي خلصت (النتيجة النهائية؛ سين جيم: كل الأسئلة؛ برا السالفة: جولات بعدد اللاعبين، 3 على الأقل). إذا أحد بدّل في النص يطلع له تنبيه وما تنحسب لأحد.
- «🏁 خلصنا السهرة» يطلع بطل الليلة 👑 للكل.
- الملف: `fnnight.js` (محمّل في كل لعبة). قاعدة البيانات: `night/<CODE>/state`. كل غرفة تعرف رقم خطوتها في السهرة (`nt`).

## تطبيق على الجوال
- `site.webmanifest` + الأيقونات (`icon-192.png`، `icon-512.png`، `icon-maskable-512.png`).
- `fninstall.js` يطلع شريط «حمّل» في الصفحة الرئيسية: الأندرويد بضغطة، والآيفون يشرح خطوات «إضافة إلى الشاشة الرئيسية».

## صور سين جيم (صفحة `pick/`)
- الأسئلة اللي ما تنحل بدون صورة معلّمة بـ `r:1` ومخفية من اللعب لين تنضاف صورتها.
- افتح `pick/` (أو من «الصور المطلوبة» في سين جيم)، والصق مفتاح TMDB (ينحفظ في المتصفح بس).
- لكل سؤال: اختار صورة من TMDB، أو ارفع لقطة، أو «ما تحتاج صورة»، أو «احذف السؤال».
- صدّر الملف وارفعه لمجلد `picks/` في GitHub. الـ Action (`apply-picks.yml`) يصغّر الصور (1024px) ويحطها في `img/` ويحدّث الأسئلة وينشر الموقع.
- الصور من TMDB، وسطر الذكر موجود تحت صفحة سين جيم.

## المحتوى
- `seenjeem/index.html`: أسئلة سين جيم، والصور في `img/`
- `outside/words.json`: أقسام وكلمات برا السالفة
- `sedq/questions.json`: أسئلة صدق ولا كذب
- `mf/questions.json`: أسئلة مين فينا
- `draw/words.json`: كلمات ارسم وخمّن
- `dafour/questions.json`: أسئلة الدافور (`options` أربع خيارات، `note` معلومة اختيارية). رقم الجواب الصحيح مخفي في `k` عشان ما ينقرا من الملف وسط اللعب (يتحسب من `answer` و`id`، شف `dafour/app.js`). الخيارات تنخلط كل مرة.

## ملفات مشتركة
- `fnnight.js`: السهرة وزر «🔄 بدّل اللعبة» (محمّل في كل لعبة)
- `fnanim.js` و `fnfx.js`: الحركات (احتفال، فائز…) والأصوات وزر كتم الصوت
- `fnwake.js`: يخلي شاشة صاحب الغرفة صاحية (هو اللي يشغّل المؤقتات)
- `fninstall.js`: شريط «حمّل Friday Night على جوالك»
- `draw/board.js`: لوحة الرسم (للعبة وشاشة العرض): خطوط و🪣 تعبئة، وصورة الرسمة للمعرض
- `fncrypto.js`: تشفير أسرار الغرف (الأدوار، التصويت، الكذبات، الأجوبة) عشان محد يقدر يغش من قاعدة البيانات
- `shim.js` و `sw.js`: تشغيل سين جيم على Firebase وعرض صور «فئاتي»
- `firebase-config.js`: إعدادات Firebase
- `database.rules.json`: قواعد قاعدة البيانات. **أي تعديل عليها لازم ينلصق في Firebase** (Realtime Database ← Rules ← Publish)
- `scripts/localize_tmdb.py`: ينزّل صور TMDB داخل `img/` (يشتغل تلقائي على GitHub Actions)

## الأسئلة ما تتكرر
الدافور وصدق ولا كذب وارسم وخمّن: كل جوال يحفظ الأسئلة/الكلمات اللي شافها (`df-seen-v1`، `sq-seen-v1`، `draw-seen-v1`)،
وكل لاعب يرسل آخرها مع اسمه (`sn`). صاحب الغرفة يختار اللي محد شافه، ولما يخلص كل شي يرجع الأقدم أول.

## معرض ارسم وخمّن
كل رسمة تنحفظ صورة صغيرة في `media/<id>` (32 حرف). آخر اللعبة (3 لاعبين وأكثر) الكل يصوّت لأحلى وأسوأ رسمة
(أحلى رسمة +10). الصور القديمة تنمسح أول ما تبدأ لعبة جديدة بنفس الغرفة.

## الرجوع للغرفة
فتح اللعبة بدون رمز يرجّعك لغرفتك بس إذا اللعبة شغالة وكنت فيها قبل أقل من ربع ساعة. السهرة اللي لها أكثر من 4 ساعات بدون تبديل ما تنقل أحد.

## قبل كل نشر
- `python3 scripts/stamp.py` يحط رقم نسخة جديد على ملفات الموقع (`app.js?v=…`) عشان الجوالات ما تشغّل نسخة قديمة محفوظة.

## إعداد Firebase (مرة وحدة)
1. console.firebase.google.com ← Create project (بدون Google Analytics).
2. Build ← Realtime Database ← Create database ← Start in **locked mode**.
3. تبويب Rules ← الصق محتوى `database.rules.json` ← Publish.
4. Project settings ← Your apps ← أيقونة الويب `</>` ← انسخ `databaseURL` و `projectId` إلى `firebase-config.js`.

إذا `firebase-config.js` على `null`، تشتغل سين جيم وبرا السالفة على جهاز واحد بس.
